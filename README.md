# Python-механизм

Интерактивный обучающий сайт по базовым командам Python. Детали можно перетаскивать в линию сборки, запускать механизм и видеть, почему команда работает.

## Файлы

- `index.html` - разметка сайта.
- `style.css` - внешний вид.
- `script.js` - логика уровней и перетаскивания.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи туда `index.html`, `style.css`, `script.js` и `README.md`.
3. Открой `Settings` -> `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. В `Branch` выбери `main` и папку `/root`, затем нажми `Save`.
6. Подожди примерно минуту. GitHub покажет ссылку на сайт.
