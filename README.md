# Python-механизм

Интерактивный обучающий сайт по базовым командам Python. Ученик собирает код из деталей: перетаскивает или кликает по элементам, вставляет их в гнезда механизма, видит собранную строку кода и запускает цепь.

Внутри 10 заданий: переменные, `print()`, `input()`, `if`, `if / else`, `for`, списки, словари, `def` и `return`.

## Что умеет тренажер

- детали можно перетаскивать в гнезда или вставлять кликом;
- каждое гнездо подсвечивает правильную, ошибочную или пустую деталь;
- код Python собирается в реальном времени;
- механизм запускает анимацию шестерней, кабелей, датчика давления и искр;
- есть модификаторы: контуры деталей, автозапуск и строгая посадка;
- диагностика цепи показывает, где именно сборка еще не совпала с Python-командой.

## Файлы

- `index.html` - разметка сайта.
- `style.css` - внешний вид, состояния деталей и анимации механизма.
- `script.js` - логика уроков, drag-and-drop, проверка сборки и запуск.
- `README.md` - описание проекта.

## Публикация на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи туда `index.html`, `style.css`, `script.js` и `README.md`.
3. Открой `Settings` -> `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. В `Branch` выбери `main` и папку `/root`, затем нажми `Save`.
6. Подожди примерно минуту. GitHub покажет ссылку на сайт.
