Словарь деталей

Как детали превращаются в Python

Коробка

Переменная

Имя места, где Python хранит данные: число, текст или другой объект.

Пакет

Значение

То, что кладем в переменную: например, 10 или "Mira".

Транспортер

Знак =

Команда "положи значение справа в переменную слева".

Проектор

print()

Показывает текст или значение переменной на экране результата.

Микрофон

input()

Просит пользователя ввести данные и передает их программе.

Ворота

if

Пропускают команду только если условие получилось истинным.

Публикация

Как выложить на GitHub Pages

  1. Создай новый репозиторий на GitHub, например python-mechanism.
  2. Загрузи в него файлы index.html, style.css и script.js.
  3. Открой репозиторий, зайди в Settings, потом в Pages.
  4. В блоке Build and deployment выбери Deploy from a branch.
  5. В Branch выбери main и папку /root, затем нажми Save.
  6. Через минуту GitHub даст ссылку вида https://имя.github.io/python-mechanism/.
