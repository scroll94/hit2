Как механизм говорит на Python

Коробка

Переменная

Имя места, где Python хранит данные: число, текст, список или результат функции.

Пакет

Значение

То, что кладется в переменную: 7, "Mira", [1, 2, 3].

Транспортер

=

Переносит значение справа в коробку слева.

Проектор

print()

Выводит на экран то, что стоит внутри скобок.

Микрофон

input()

Просит пользователя ввести данные и возвращает ответ в программу.

Ворота

if / else

Открывают разные пути в зависимости от условия.

Мотор

for

Повторяет команду несколько раз.

Чертеж

def

Создает свою команду, которую можно запускать по имени.

Склад

list / dict

Хранит много значений сразу: по порядку или по ключам.

Публикация

Как выложить на GitHub Pages

  1. Создай новый репозиторий на GitHub, например python-mechanism.
  2. Загрузи файлы index.html, style.css, script.js и README.md.
  3. Открой репозиторий, зайди в Settings, потом в Pages.
  4. В Build and deployment выбери Deploy from a branch.
  5. В Branch выбери main и папку /root, затем нажми Save.
  6. Через минуту GitHub даст ссылку вида https://имя.github.io/python-mechanism/.
